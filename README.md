# Academia de Judô — Landing Page

Landing page moderna desenvolvida para uma academia de Judô, com foco em identidade visual forte, experiência do usuário e design premium.

O projeto foi criado para transmitir:
- Disciplina
- Força
- Tradição
- Modernidade

Com uma interface fluida, responsiva e visualmente impactante.

---

# Destaques do Projeto

- Interface moderna e imersiva
- Design responsivo para mobile, tablet e desktop
- Navegação fluida e intuitiva
- Animações suaves e elegantes
- Efeitos visuais premium
- Estrutura otimizada para performance
- Layout focado em conversão
