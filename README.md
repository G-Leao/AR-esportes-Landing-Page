# Academia de Judô — Landing Page

Projeto de uma landing page moderna para academia de Judô, desenvolvido com foco em:
- Design moderno
- Responsividade
- Performance
- Experiência do usuário

---

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Remix Icons

---

## Funcionalidades

- Hero section moderna
- Sessão sobre a academia
- Planos de treino
- Galeria de imagens
- Sessão de localização
- Layout responsivo
- Efeitos visuais suaves
- Navegação fluida
